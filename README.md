# LOOK product listing
Static site, no build step.

## Product photos (simple)
Put your product photos in the assets folder and name them 1.png, 2.png, 3.png ... (up to 6). .jpg also works.
In Figma you can type just "1" as the export name; Figma adds .png.
Cards cycle through whatever photos you add. Each card's carousel shows the photo and a zoomed-in close-up of it.
Optional: assets/logo.png for the LOOK logo.
